# Examples
### Small projects in scientific computing, data analysis, and practical problem solving

A growing collection of focused projects and exercises by **Saxon Honey**, a scientist with a Ph.D. in Molecular & Cellular Biology and experience spanning biological research, scientific software, imaging, and practical engineering.

This repository is a place to explore different programming languages, develop useful tools, and demonstrate how I approach technical problems—from organizing messy data to building reproducible analyses and improving research workflows.

## Areas of exploration

| Area | Topics |
| --- | --- |
| **Python** | Data processing, automation, scientific computing, and small utilities |
| **SQL** | Relational data modeling, joins, aggregations, and data quality checks |
| **R** | Statistical analysis, biological data exploration, and visualization |
| **Imaging** | Image processing, quantitative measurements, and analysis workflows |
| **Systems & workflows** | Requirements, tool integration, troubleshooting, and process improvement |

These are directions for the collection as it grows; they do not imply that a completed example exists for every topic.

## Project approach

The emphasis is on clear reasoning and useful results. Project documentation will explain:

- **The problem:** What question or practical need does the example address?
- **The approach:** How does the solution work, and why was it chosen?
- **The result:** What does the code produce, and how can the output be checked?
- **The limitations:** What assumptions, tradeoffs, or next steps matter?

Some entries will be short learning exercises; others will develop into more complete tools or analyses. Their scope and status will be identified in the accompanying notes.

## Running the examples

Examples are intended to be explored independently. Consult the notes in the relevant project folder for dependencies, input data, and execution instructions as projects are added.
